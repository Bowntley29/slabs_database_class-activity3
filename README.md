# 1. Vertical vs. Horizontal Software:
- Real-world example of a Vertical package: A clinic management system for a hospital in Soweto
- Real-world example of a Horizontal package: Microsoft Excel which can be used at a bank, school or a shop.
Difference between a Vertical package and Horizontal package is that a Vertical package is narrow and specific, it is built for one industry. For Horizontal package it is broad and general, built for all industries.

# 2. Operating System Modes:
- Batch Processing: Are programs or data transactions are collected into groups and processed together all at once without direct interactive user intervention. An industrial scenario that it can use is an end-of-month payroll processing, generating monthly bank statements, or utility billing systems where immediate feedback is not required.
- Real-Time Processing: Systems that process data immediately upon receipt and respond to events within a fixed, strict time interval.An inustrial scenario that can be used in critical time-sensitive environments like flight control or radar systems, interactive banking ATMs, or laboratory equipment monitoring.
